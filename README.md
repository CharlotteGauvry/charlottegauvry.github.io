# Site académique de Charlotte Gauvry

Page personnelle hébergée sur GitHub Pages : philosophie de la conscience, recherche, publications et CV.

🔗 Voir la page : https://tonpseudo.github.io

## Contenu du dépôt

- `index.html` — la page (bio, recherche, publications, CV, contact)
- `photo.jpg` — photo de profil affichée en haut de page
- `cv.pdf` — CV à ajouter (référencé par la page, non inclus ici)

## Mise à jour

Pour modifier le contenu (bio, publications, liens), éditer directement `index.html` et déposer les changements ("commit") sur la branche `main` : GitHub Pages republie automatiquement en quelques minutes.
